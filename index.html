1 Draft a new pact

Write it in plain words.

Write the agreement, name who's on the other side, and prove who you are. You'll sign it before it goes on-chain.

Write a test, not a wish. The jury reads the text of your evidence page and checks it against these words. It is good at facts it can see, and it cannot judge taste or effort.
Checkable: “a file named logo.svg exists in the repo” · “the post is at least 500 words and mentions X, Y and Z” · “the README lists a Pricing section”.
Not checkable: “a good logo” · “a professional website” · “real effort”. If you don’t set a bar, anything that exists will pass — a one-line article still counts as an article, and a one-line website still counts as a website.
Images can’t be judged at all. The jury reads text only. It can confirm an image file is there and named what you agreed; it can never see whether the picture is the one you wanted. Agree the artwork between yourselves, and use the pact for the part a machine can actually verify.
Using a suggestion below? It’s a worked example, not text to use as-is — file names like logo.svg or section names like Pricing are placeholders. Replace them with your actual deliverable, or the jury will correctly rule not fulfilled against evidence that never had those exact words.
⚠ The page must be public and readable without logging in.
Works: GitHub files and repos, raw.githubusercontent.com, blog posts, docs, any plain public web page.
Doesn't work: X/Twitter, Instagram, LinkedIn, Discord, private Google Docs. These block automated reading, so the jury sees an empty page and rules not fulfilled.
Quick test: open the link in a private/incognito window. If you can see the proof there without signing in, the jury can too.

* All fields are required. You'll review and sign the pact on the next screen.

Welcome to Pact

A pact is a two-person agreement that lives on the blockchain. You write it in plain words, both people sign it with their wallets, and when the deadline arrives an AI jury reads the evidence online and decides whether it was kept.

  1. Draft a pact: write the deal, add the other person's address, and link both identities.
  2. Both sign: you sign when you create it; the other person opens it and signs too. Once both have signed, the pact goes live and a unique signature token is minted on-chain.
  3. Settle: after the deadline, anyone can ask the AI jury to read the evidence and rule whether the agreement was fulfilled.

A demo on the GenLayer Studio network. The jury records a verdict; no funds move. Not financial or legal advice.
